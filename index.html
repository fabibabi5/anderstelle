🚀 So geht's in der Vorlesung

  1. Im Projektordner einen lokalen Server starten: python3 -m http.server 8000 und in Google Chrome http://localhost:8000 öffnen.
  2. Optional, aber empfohlen: in einem zweiten Terminal ./vosk/start.sh – dann zählt Vosk mit und erwischt deutlich mehr. Der Status oben wird grün.
  3. Wal-Party öffnen, auf Start klicken und das Mikrofon erlauben.
  4. Mac-Tipp: Während Chrome das Mikro nutzt, im Kontrollzentrum „Mikrofonmodus“ auf Standard stellen (nicht „Sprachisolierung“). Tab im Vordergrund lassen.
  5. Lag die Erkennung daneben? Im Panel 🔍 Diagnose mit V (verpasst) bzw. F (falsch gezählt) markieren – das korrigiert den Zähler und hilft beim Verbessern.
Erkennung über Chrome (Audio geht zur Verarbeitung an Google) und optional Vosk (läuft komplett lokal). Zählerstand, Statistik und Diagnose-Sitzungen bleiben im Browser auf diesem Rechner.
